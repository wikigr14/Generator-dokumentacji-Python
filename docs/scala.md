# Dokumentacja API Scali

Poniżej znajduje się automatycznie wygenerowana dokumentacja Scaladoc dla modułu
implementującego wzorzec projektowy **Strategia** (pakiet `payment`).

!!! info "Generowanie dokumentacji"
    Dokumentacja Scaladoc jest generowana automatycznie przez `sbt doc` w potoku CI/CD.
    Lokalne uruchomienie: `sbt doc` → pliki trafiają do `target/scala-2.13/api/`.
