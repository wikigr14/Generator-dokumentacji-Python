# Witaj w Projekcie 18

To jest główna strona naszej automatycznie generowanej i wersjonowanej dokumentacji.

Skorzystaj z zakładek w menu powyżej, aby przeglądać dokumentację wygenerowaną prosto z kodu źródłowego projektów napisanych w językach Python oraz Scala.

## Szybki start

- Moduł Pythona został wygenerowany za pomocą wtyczki `mkdocstrings`.
- Moduł Scali to w pełni zintegrowany natywny format `Scaladoc`.
- Diagramy architektoniczne są generowane automatycznie z kodu źródłowego.
