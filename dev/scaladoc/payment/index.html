  1.  class CreditCardPayment extends PaymentStrategy

    Strategia płatności kartą kredytową.

    Strategia płatności kartą kredytową.

    Konkretna implementacja traitu PaymentStrategy. Odpowiada za symulację logiki autoryzacji i pobierania środków z karty kredytowej.

    Przykład użycia

    val strategy: PaymentStrategy = new CreditCardPayment("4111111111111111")
val result = strategy.pay(99.99)
// result: "Zapłacono 99.99 PLN kartą kredytową (nr: ****1111)."
